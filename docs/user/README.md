# ChannelForge User Documentation

Start here: **[Home](Home.md)**

This directory is the task-oriented, user-facing documentation for ChannelForge — guides for people running and configuring the project. Engineering documentation (architecture, ADRs, contribution rules, internal design) stays elsewhere in the repository and remains the canonical source of truth; see [DOCUMENTATION.md](../../DOCUMENTATION.md).

## Pages

- [Home](Home.md) — start here; routes you to the right page based on what you're trying to do
- [What Is ChannelForge?](What-Is-ChannelForge.md) — what it is, current maturity, what it does and doesn't do yet
- [Build Your First Lineup](Build-Your-First-Lineup.md) — the shortest path from a clone to a working output
- [Safe Local Configuration](SAFE_LOCAL_CONFIGURATION.md) — setting up real provider data without ever touching a tracked file
- [Current Limitations](CURRENT_LIMITATIONS.md) — what's implemented vs. planned, stated honestly
- [Troubleshooting](TROUBLESHOOTING.md) — fixing problems yourself, and reporting one safely
- [The ChannelForge Way](THE_CHANNELFORGE_WAY.md) — project mindset and philosophy
- [Quick Start](QUICK_START.md) — verifying your development environment works
- [First Plex Smoke Test](PLEX_SMOKE_TEST.md) — full walkthrough of testing a real lineup in Plex

This documentation set is built incrementally, in reviewable commits — see [Issue #12](https://github.com/Jumpstile/ChannelForge/issues/12) for progress.
