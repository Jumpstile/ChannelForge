# ChannelForge Canonical Abstraction and Lifecycle Matrix

## Purpose

This document is the repository artifact for issue #75 and ADR 0008.

It defines ownership, lifecycle, authority, mutation boundaries, persistence expectations, review expectations, and verification gates for ChannelForge's canonical abstractions.

The matrix does not implement features, select storage technology, or authorize updater work.

## Relationship to the architecture ADRs

ADR 0003 establishes the layered architecture and dependency direction.

ADR 0007 establishes logical module boundaries.

ADR 0008 requires canonical, target-neutral abstractions with explicit ownership and lifecycle. Provider-owned service state remains outside ChannelForge ownership.

ADR 0009 governs durable state, persistence, retention, recovery, and last-known-good handling.

ADR 0010 governs deterministic identifiers, runs, decisions, and artifacts.

ADR 0011 governs security, audit, redaction, trust boundaries, and update integrity.

## Forbidden shortcuts

The following shortcuts are prohibited:

- UI directly mutating canonical identity, evidence, durable state, provider state, or publication artifacts.
- Provider/guide adapters rewriting canonical identity or evidence confidence.
- Durable storage applying domain business rules.
- Output/publication rewriting canonical identity or evidence.
- Security/audit bypassing module ownership contracts.
- Preflight/certification paths triggering repair or mutation.
