# Channel Identity Model

ChannelForge treats channel identity as more important than provider names.

Provider names can change. Channel identity should remain stable.

## A channel identity may include

- Canonical name
- Station call sign
- Network
- Affiliate
- Market
- Country
- Language
- Virtual channel number
- RF channel number
- Provider names
- Aliases
- XMLTV guide IDs
- Logo references
- Previous build history
- Evidence sources
- Confidence score

## Example

WBRE is not just a string in a playlist.

WBRE is:

- NBC affiliate
- Scranton/Wilkes-Barre market
- Virtual channel 28
- Local Pennsylvania station
- Known by multiple provider names and guide IDs

## Rule

Provider labels are evidence.

They are not truth by themselves.
