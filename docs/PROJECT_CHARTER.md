# ChannelForge Project Charter

ChannelForge exists to produce accurate, trustworthy, deterministic television lineups through verifiable evidence, transparent decision-making, and uncompromising engineering discipline.

## Mission

Build an evidence-driven television knowledge engine that can import provider data, verify channel identity, detect drift, self-heal safely, and generate reliable outputs for IPTVBoss, Dispatcharr, Plex, and future platforms.

## Core promise

ChannelForge does not guess. It verifies.

## Success criteria

ChannelForge succeeds when it can:

- Import provider playlists.
- Verify channels using multiple evidence sources.
- Preserve user intent.
- Detect provider drift.
- Repair safe changes automatically.
- Escalate uncertain changes for review.
- Generate usable output files.
- Explain every important decision.

## Non-goals

ChannelForge is not:

- A blind playlist editor.
- A black-box AI guesser.
- A replacement for user judgment.
- A tool that silently overwrites production data.

## Highest rule

It has to work.
